# Project 04 - Personal Portfolio (Capstone)

## Description
An authentic, responsive personal developer portfolio built entirely from scratch using semantic HTML5, modern CSS3, ES6+ JavaScript, and Git version control without any external frameworks or UI libraries[cite: 14].

## Features
- Semantic and structured HTML layout.
- Fully responsive design using Flexbox and CSS Grid.
- Dynamic Theme Switcher (Dark/Light mode) powered by JavaScript event listeners.
- Interactive sections showcasing prior projects (00 to 03).
